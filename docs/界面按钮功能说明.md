# Ktr启停管理工具——界面按钮功能说明

适用版本：`v0.3.0`

## 一、工具用途

本工具用于读取 Pentaho Data Integration / Kettle 的 `.ktr` 转换文件，并可视化管理转换中各条 hop（步骤之间的连线）的启用、禁用状态。

工具只修改 `<order><hop><enabled>` 中的 `Y/N` 状态，不连接数据库，也不会执行 KTR 转换。

## 二、按钮功能

### 1. 打开 KTR

作用：

- 打开文件选择窗口，选择需要管理的 `.ktr` 转换文件。
- 读取 KTR 中的转换名称、来源步骤、目标步骤和 hop 启用状态。
- 在列表底部显示 hop 总数、启用数、禁用数和待保存更改数。

注意事项：

- 如果当前文件存在未保存更改，打开其他文件前会询问是否放弃这些更改。
- 只接受根节点为 `<transformation>`，且包含可识别 hop 的 KTR 文件。

### 2. 选择当前列表

作用：

- 一次选中当前列表中可见的全部 hop。
- 可配合“搜索”和“筛选”使用，实现按条件批量选择。

示例：

1. 在搜索框输入 `V_M_CLI`。
2. 列表只显示名称包含 `V_M_CLI` 的 hop。
3. 点击“选择当前列表”。
4. 再点击“启用选中”或“停用选中”。

注意事项：

- 只选中当前显示的项目，不会选中被搜索或筛选条件隐藏的项目。
- 此按钮本身不会改变任何启用状态。

### 3. 启用选中

作用：

- 将列表中当前选中的一条或多条 hop 设置为启用状态。
- 对应 KTR 中的状态为 `<enabled>Y</enabled>`。

前置条件：

- 必须先选择至少一条 hop。
- 可使用 `Ctrl`、`Shift` 或“选择当前列表”进行多选。

影响：

- 只改变界面中的待保存状态。
- 点击后不会立即修改磁盘上的 KTR 文件，需要继续使用保存按钮。

### 4. 停用选中

作用：

- 将列表中当前选中的一条或多条 hop 设置为禁用状态。
- 对应 KTR 中的状态为 `<enabled>N</enabled>`。

前置条件：

- 必须先选择至少一条 hop。

影响：

- 只改变界面中的待保存状态。
- 点击后不会立即修改磁盘上的 KTR 文件。

### 5. 仅启用选中

作用：

- 启用当前选中的 hop。
- 同时停用当前 KTR 中其余所有 hop。

典型用途：

- 单独调试一个视图转换。
- 同时调试少数几个指定视图转换。

执行过程：

1. 选择需要调试的一条或多条 hop。
2. 点击“仅启用选中”。
3. 工具显示将启用和停用的数量，并请求确认。
4. 确认后更新界面中的待保存状态。

注意事项：

- 该按钮影响整个 KTR，不只是当前搜索或筛选结果。
- 被隐藏但没有选中的 hop 也会被停用。
- 点击后仍需保存才会写入文件。

### 6. 全部启用

作用：

- 将当前 KTR 中的全部 hop 设置为启用状态。

执行过程：

- 点击后会显示确认窗口。
- 确认后，全部 hop 在界面中变为启用状态。

注意事项：

- 影响整个 KTR，包括当前未显示的项目。
- 搜索和筛选条件不会限制该按钮的作用范围。
- 点击后仍需保存才会写入文件。

### 7. 全部停用

作用：

- 将当前 KTR 中的全部 hop 设置为禁用状态。

执行过程：

- 点击后会显示确认窗口。
- 确认后，全部 hop 在界面中变为禁用状态。

注意事项：

- 影响整个 KTR，包括当前未显示的项目。
- 点击后仍需保存才会写入文件。

### 8. 撤销未保存更改

作用：

- 放弃本次打开文件后，在界面中进行的全部未保存状态调整。
- 将每条 hop 恢复到最近一次打开或保存成功时的状态。

执行过程：

- 只有存在未保存更改时才会执行。
- 点击后会显示确认窗口。

注意事项：

- 不会修改磁盘上的 KTR 文件。
- 不能撤销已经保存到磁盘的更改。
- 如果需要恢复已经覆盖保存的文件，应使用工具自动生成的 `.bak-时间戳` 备份文件。

### 9. 安全校验

作用：

- 在不保存文件的情况下，对当前计划中的更改进行安全校验。

校验内容：

- 修改后的内容仍然是有效 XML。
- 计划启用后的有向数据流不存在循环。
- 每条 hop 引用的来源步骤和目标步骤真实存在。
- 不存在重复步骤名或重复 hop。
- hop 总数没有变化。
- 每条 hop 的来源步骤和目标步骤没有变化。
- 实际状态与界面计划状态一致。
- 除 hop 的 `<enabled>` 值外，没有其他文本被修改。
- 输出文件的字节长度没有发生意外变化。

结果：

- 校验通过：显示 hop 数量和计划修改的状态数量。
- 校验失败：停止操作并显示错误原因，不写入文件。
- 完整分支部分启用属于提示项，会明确列出但不会直接阻止保存。

### 10. 备份并覆盖原文件

作用：

- 将当前界面中的状态更改保存回原 KTR 文件。
- 覆盖前在原文件所在目录自动创建时间戳备份。

备份文件示例：

```text
原文件名.ktr.bak-20260919-153000
```

安全机制：

- 没有未保存更改时不会执行覆盖。
- 保存前会再次执行完整校验。
- 安全校验通过后，会先逐条显示“原状态 → 保存后状态”；只有确认变更预览后才会覆盖文件。
- 如果源文件在打开后被 Spoon 或其他程序修改，工具会拒绝覆盖，避免丢失外部更改。
- 使用临时文件完成写入后再替换原文件，降低写入中断造成文件损坏的风险。

注意事项：

- 覆盖前应确认 Spoon 没有同时保存同一个文件。
- 保存成功后，应在 Spoon 中重新打开或重新加载 KTR。

### 11. 保存副本…

作用：

- 将当前界面中的状态保存为一个新的 `.ktr` 文件。
- 不修改当前打开的原 KTR 文件。

默认文件名：

```text
原文件名_已调整.ktr
```

安全机制：

- 保存前执行与“安全校验”按钮相同的完整检查。
- 安全校验通过后，会先显示完整的启用、禁用变更预览。
- 不允许通过“保存副本”功能直接覆盖当前原文件。

建议：

- 首次使用或大批量修改时，优先选择“保存副本”。
- 使用 Spoon 打开副本并检查连线状态，确认无误后再投入调试或替换正式文件。

### 12. 启用所选分支

作用：

- 选中某个完整分支内的任意一条 hop，即可启用该分支包含的全部 hop。
- 同时选择多个分支中的 hop，可以一次启用多个完整分支。

完整分支定义：

- 工具忽略 hop 的箭头方向，把所有能够相互连通的步骤识别为一个完整分支。
- 分支识别使用 KTR 中的全部 hop，包括当前处于禁用状态的 hop。

安全机制：

- 执行前显示涉及的分支数和 hop 数。
- 如果启用完整分支会形成数据流循环，本次操作会被自动撤销。

### 13. 停用所选分支

作用：

- 停用选中 hop 所属完整分支中的全部 hop。
- 避免只停用链路中间一条 hop，留下部分启用的残缺数据流。

注意事项：

- 选中同一分支中的多条 hop，只会对该分支执行一次。
- 操作只改变界面待保存状态，确认保存前不会修改磁盘文件。

### 14. 仅启用所选分支

作用：

- 完整启用当前选中的一个或多个分支。
- 同时停用当前 KTR 中的其他全部分支。

典型用途：

- 调试包含多个步骤的完整接口链路。
- 避免使用“仅启用选中”时只启用复杂分支中的一部分 hop。

安全机制：

- 执行前显示将保留启用的分支数及 hop 数。
- 操作形成循环时自动撤销。
- 保存前仍需通过安全校验和变更预览。

## 三、其他界面控件

### 搜索框

- 按来源步骤或目标步骤名称实时搜索。
- 不区分英文字母大小写。
- 搜索只影响列表显示，不会自动改变 hop 状态。

### 筛选下拉框

支持以下选项：

| 筛选项 | 含义 |
|---|---|
| 全部 | 显示全部 hop |
| 当前启用 | 只显示当前为启用状态的 hop |
| 当前禁用 | 只显示当前为禁用状态的 hop |
| 已修改 | 只显示与打开文件时相比发生变化、但尚未保存的 hop |
| 分支部分启用 | 只显示所属完整分支没有全部启用或全部停用的 hop |

### 列表多选

- `Ctrl + 单击`：逐条增加或取消选择。
- `Shift + 单击`：连续选择多条。
- 双击某一行：切换该条 hop 的启用或禁用状态。

### 状态汇总

界面底部显示：

- hop 总数；
- 当前启用数量；
- 当前禁用数量；
- 待保存更改数量；
- 当前列表显示数量。

“待保存更改”大于 `0` 时，表示界面状态与磁盘文件状态存在差异。

## 四、推荐操作流程

### 单独调试一个视图

1. 点击“打开 KTR”。
2. 搜索视图名称。
3. 选中对应 hop。
4. 点击“仅启用所选分支”；对于当前这种一条 hop 的简单分支，也可使用“仅启用选中”。
5. 点击“安全校验”。
6. 点击“保存副本…”。
7. 使用 Spoon 打开副本，确认只有目标连线处于启用状态。

### 批量启用或停用一组视图

1. 使用搜索或筛选缩小范围。
2. 点击“选择当前列表”，或使用 `Ctrl/Shift` 手动多选。
3. 简单两步链路可点击“启用选中”或“停用选中”；复杂链路建议使用完整分支按钮。
4. 查看底部数量和黄色的已修改行。
5. 点击“安全校验”。
6. 保存副本，或备份并覆盖原文件。

## 五、状态变化与文件写入关系

| 操作 | 改变界面状态 | 修改磁盘文件 | 创建备份 |
|---|---:|---:|---:|
| 启用选中 | 是 | 否 | 否 |
| 停用选中 | 是 | 否 | 否 |
| 仅启用选中 | 是 | 否 | 否 |
| 全部启用 | 是 | 否 | 否 |
| 全部停用 | 是 | 否 | 否 |
| 启用所选分支 | 是 | 否 | 否 |
| 停用所选分支 | 是 | 否 | 否 |
| 仅启用所选分支 | 是 | 否 | 否 |
| 撤销未保存更改 | 是 | 否 | 否 |
| 安全校验 | 否 | 否 | 否 |
| 保存副本 | 否 | 新建副本 | 否 |
| 备份并覆盖原文件 | 否 | 是 | 是 |

## 六、重要提醒

- 本工具管理的是 transformation hop，不是步骤本身，也不是 KJB job hop。
- 修改状态后必须点击保存按钮，磁盘文件才会发生变化。
- 每次保存前必须通过结构安全检查，并确认逐条变更预览。
- 建议不要让 Spoon 和本工具同时保存同一个 KTR。
- 保存成功后，应让 Spoon 重新加载文件，否则 Spoon 可能仍显示内存中的旧状态。
- 工具不会验证数据库连接、SQL语句或目标表结构；运行转换前仍应按照原有流程检查。
